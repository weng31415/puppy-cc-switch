## Set up an application

Sign in to PuppyRouter in your browser using the account button in the app. Select an application in the sidebar, then select its API key. Click Enable on the PuppyRouter provider to apply it. Each application has its own selection.

You can also add custom providers. Direct, Route and Stack modes, MCP, Skills, prompts and sessions are available according to the selected application.
