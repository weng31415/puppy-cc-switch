## 配置一个应用

从客户端的账户入口在浏览器登录 PuppyRouter。在侧边栏选择目标应用，再为它选择 API Key。点击 PuppyRouter 供应商的「启用」后配置才会生效。每个应用可以选择不同的密钥。

你也可以添加自定义供应商。直连、路由、聚合、MCP、Skills、提示词和会话管理的可用范围取决于所选应用。
