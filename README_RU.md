## Настройка приложения

Нажмите кнопку учётной записи и войдите в PuppyRouter через браузер. Выберите приложение на боковой панели и укажите его API-ключ. Чтобы применить настройки, включите поставщика PuppyRouter. Ключ можно выбирать отдельно для каждого приложения.

Вы также можете добавить своего поставщика. Поддержка прямого подключения, маршрутизации, агрегации, MCP, Skills, промптов и сеансов зависит от приложения.
