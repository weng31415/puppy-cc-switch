## 앱 설정

앱의 계정 버튼을 눌러 브라우저에서 PuppyRouter에 로그인하세요. 사이드바에서 앱을 선택하고 사용할 API 키를 고른 뒤 PuppyRouter 공급자를 활성화하면 설정이 적용됩니다. 앱마다 별도의 키를 선택할 수 있습니다.

사용자 지정 공급자도 추가할 수 있습니다. 직접 연결, 라우팅, 통합, MCP, Skills, 프롬프트 및 세션 관리는 선택한 앱에 따라 지원 범위가 다릅니다.
