## 設定應用程式

透過用戶端的帳戶入口在瀏覽器登入 PuppyRouter。在側邊欄選擇目標應用程式，再為它選擇 API 金鑰。點選 PuppyRouter 供應商的「啟用」即可套用設定。每個應用程式可以使用不同的金鑰。

你也可以新增自訂供應商。直連、路由、聚合、MCP、Skills、提示詞及工作階段管理的可用範圍取決於所選的應用程式。
