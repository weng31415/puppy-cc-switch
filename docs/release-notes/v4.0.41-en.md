# PuppyRouter Tool 4.0.41

- Click the sidebar version to check for updates and open the installer in About.
- Windows portable downloads use the correct ZIP. Linux DEB supports background update downloads.

Installed copies of 3.19.5 can upgrade directly to 4.0.41. Open Settings → About, check for updates, then select the new version. The app keeps your account, providers and key selections and attempts to back up the old database before migration. For Windows portable, quit the app and extract the new ZIP.
