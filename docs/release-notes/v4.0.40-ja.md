# PuppyRouter App 4.0.40

- サイドバーで 16 個のアプリを管理し、アプリごとに PuppyRouter キーを設定できます。
- Grok 公式カードに xAI アカウントを紐付けて切り替え可能に
- プラグイン画面が Antigravity CLI に対応
- 使用量でプロバイダー別・モデル別のキャッシュヒット率を表示

3.19.5 から更新しても、アカウント、プロバイダー、選択済みのキー、カスタムモデルは引き継がれます。追加されたアプリではキーを個別に選択して有効にしてください。対応アプリでは直結、ルーティング、集約を選べます。Grok Build では MCP、Skills、プロンプト、セッションを管理でき、元の公式ログインにも戻せます。

セキュリティチェックを強化し、データベース・ルーティング・会話検索を高速化
