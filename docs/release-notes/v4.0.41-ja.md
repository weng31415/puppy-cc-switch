# PuppyRouter Tool 4.0.41

- サイドバーのバージョンをクリックして更新を確認し、アプリ内でインストールできます。
- Windows ポータブル版の ZIP 配布を修正し、Linux DEB の更新をバックグラウンドで取得できます。

3.19.5 のインストール版から 4.0.41 に直接更新できます。「設定 → このアプリについて」で更新を確認し、新しいバージョンを選んでください。アカウント、プロバイダー、キーの選択は引き継がれます。初回起動時に旧データベースのバックアップを試みてから移行します。Windows ポータブル版は終了してから新しい ZIP を展開してください。
