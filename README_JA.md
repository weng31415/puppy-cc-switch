## アプリを設定する

アカウントボタンからブラウザーで PuppyRouter にログインします。サイドバーで対象のアプリを選び、使いたい API キーを選択します。PuppyRouter プロバイダーを有効にすると設定が反映されます。キーはアプリごとに選べます。

独自のプロバイダーも追加できます。直結、ルーティング、集約、MCP、Skills、プロンプト、セッションの対応状況はアプリによって異なります。
